# 🐍 Python2 - Portable Installer

> Instalador rápido de Python2 para sistemas modernos (Ubuntu / VPS)

---

## ⚡ Instalación rápida (One-Line)

```bash
cd /tmp && wget -q https://raw.githubusercontent.com/SINNOMBRE22/Python2/main/py2.tar.gz && tar -xzf py2.tar.gz && mv python2 /opt/ && ln -sf /opt/python2/bin/python2.7 /usr/bin/python2 && python2 --version
